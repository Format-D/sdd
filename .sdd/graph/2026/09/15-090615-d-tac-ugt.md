For a Git-backed local target the Git finalizer is the sole committer of a capture publication: the graph store writes the entry and its attachments, and recognizes a committed publication by the trailer the finalizer wrote. The trailer is `SDD-Mutation: <batch ID>`, the line every commit in this repository's history already carries, and a capture's batch ID is its publication key rendered as `v1:` followed by a hash of session, intent sequence and discriminator, so the session handle never enters commit history. Worktree files without that commit are not a publication: a retry regenerates the summary, reuses the document already on disk and completes the commit.

No reader exists for a trailer format no release wrote. The two formats that lived inside the delivery branch, a batch ID spelling out session, sequence and discriminator and a separate `SDD-Publication:` trailer name, were removed instead of kept behind compatibility readers, because neither appears in any repository we can see and a hidden reader for an unshipped format is the compatibility subsystem 20260914-001550-d-tac-n47 rules out. A future format change bumps the version prefix and the lookup tries both prefixes for one release. The exposure of skipping a format is bounded to a capture whose commit landed but whose outcome event was lost, in a session still open across the upgrade: its retry cannot complete, the graph stays correct, and `next` with the cancel reference ends it.

A filesystem-only graph store without a Git finalizer recognizes a retry by entry ID alone and does not enforce publication-key ownership. This stays: normal local capture acquires Git-backed targets, a hosted composition supplies its own publication store, and the extension example and the procedure test world run the filesystem-only store, so they prove convergence by entry ID and nothing more.

One unresolved mutation intent gates every progression in its session, abandoning other instances included, until `next` retries it by `retry_ref` or cancels it by `cancel_ref`. That gate exceeds what 20260914-001550-d-tac-n47 requires and is chosen: an operation whose outcome is unknown is resolved by the participants before the dialogue moves on, and the two references are the only exits.

These choices sharpen 20260914-001550-d-tac-n47 in place under the idempotent-retry and explicit-continuation guarantees of 20260914-113737-d-cpt-qst, and were settled while reviewing the delivery recorded in 20260915-085829-s-tac-awi. The ruling is complete: each choice is enforced by the shipped code and its tests, and nothing follows from it unless a trailer format changes or a second local publication store arrives, each of which is its own later decision.
