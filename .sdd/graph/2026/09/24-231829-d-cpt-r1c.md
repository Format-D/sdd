In repositories used with SDD, history the graph relies on is never rewritten. A commit a done cites keeps its hash: no rebase, amend, squash or force-push on the history it lives in, usually the code repository (20260608-102216-s-prc-ijn). A commit the sdd tools made stays a commit of its own: no squash, because each carries its entry, summary or marker change and an `SDD-Mutation` trailer by which the engine recognizes its own publication when a write is retried. A rebase that replays those commits unchanged is acceptable only in a graph-only repository whose commits no done cites. Where code and graph share a repository, both rules hold, so none of its history is rewritten, and branches land by merges that keep their commits. This extends SDD's own no-rewrite sync (20260601-214603-d-tac-4ff) to agents and hosts.
