Expected, as Christopher settled it in the dialogue reviewing that evaluation: the user can end the run at any step; what happens to the code, the branch or worktree and the WIP marker, kept or released, is decided with the user, and the agent never removes code or branches without the user knowing; a later run can take up a kept marker.
