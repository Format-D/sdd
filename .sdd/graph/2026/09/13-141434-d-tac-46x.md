Serve HTTP through stateless Streamable HTTP; retain local stdio unchanged. The durable SDD session handle remains the dialogue's identity, independent of the transport. A server restart or a request reaching another replica must not require a new dialogue. Remove the transitional `StatelessHTTP` option and support one HTTP behavior. Keep the existing local HTTP command; validate it and the example against the change.

Before an MCP tool uses an existing session, authorize the current caller and reconstruct workflow state from the session store. Per-request refresh must not write the durable attachment metadata that identifies the last attached client and its last activity time. It must reconstruct from stored session events which content blocks have already been served, so ordinary requests do not repeat unchanged framing. Explicit resume records a reorientation session event that clears that reconstructed set, causing the full current position to be served again. A failed replay stops the request. If appending workflow events loses the version comparison, report the conflict with resume guidance; do not update only the version and resubmit events derived from stale state. These rules also protect local and stateful consumers from stale cached workflow objects. They do not make an entire tool call transactional.

Share graph-file classification between source adapters and `LoadSnapshotFS`. Enumerate entry and WIP documents and attachment paths without opening file bodies; materialization then reads documents, while published attachment content is read on demand through the acquired attachment reader. Local loading avoids unnecessary attachment reads. An external source service can transfer documents and attachment names in bulk without transferring every attachment body. All reads retain the acquired-view authority and lifetime defined by 20260906-234056-d-tac-bae.

The composition owns transport selection, authentication, session persistence and source storage. OSS supplies replay and shared graph interpretation, without a Git-service protocol or consumer queue or database requirements. Preserve the existing public write contract, consistent with 20260906-234852-d-tac-vdu.
